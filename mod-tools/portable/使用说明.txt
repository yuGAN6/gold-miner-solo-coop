黄金矿工：单人关卡本地双人 MOD v0.1.0

这是什么
  在原有单人关卡中加入第二个可独立操作的本地角色。
  两人独立出钩，共享金钱、目标、道具和倒计时。
  安装包是差分补丁，不包含完整游戏；接收者需要自行安装正版游戏。

支持版本
  Windows Steam 版 Gold Miner: Classic Edition，App ID 3777060。
  仅支持 build 26673644、游戏版本 2.0.0 的指定原包。
  安装器会核对整个 app.asar 的 SHA-256，相同版本号仍以哈希匹配为准。
  游戏更新、其他 MOD、不同构建均可能导致不匹配。安装器会停止，不会强行覆盖。

安装
  1. 解压整个 ZIP，保留文件夹内所有文件；不要在 ZIP 内直接运行。
  2. 关闭黄金矿工。
  3. 双击 Install.cmd。通常会自动找到 Steam 游戏；找不到时会显示目录选择器。
     选择包含 GoldMiner.exe 的游戏文件夹。
     也可以把该游戏文件夹拖到 Install.cmd 上。
  4. 等待“安装成功”，照常从 Steam 启动，选择“单人游戏”。
  不需要 Python、Java、Node.js 或 FFDec。脚本使用 Windows 自带的 PowerShell 5.1。
  CMD 中的 ExecutionPolicy Bypass 仅作用于本次脚本进程，不修改系统执行策略。
  安装失败时按提示处理；本安装器不会自动提权或关闭正在运行的游戏。

操作
  左侧 P1：原方向键。
  右侧 P2：S 出钩，W 使用炸药，A/D 对应原左/右方向键功能。
  经典模式中 A 是冰冻（需要道具），D 通常无动作。
  需要手动回收的玩法中，A/D 按原规则操作。
  矿工保留原作的自动摆钩机制，WASD 不用于自由移动。

卸载
  关闭游戏后，双击 Uninstall.cmd，选择相同游戏目录。
  原包备份位于 resources\app.asar.goldminer-coop-original，请保留。
  卸载会恢复原包，保留备份。再次运行 Install.cmd 可以重新安装。
  如果游戏已经更新，卸载器会拒绝把旧原包覆盖到新版本；此时可用 Steam 验证文件完整性。

更新与兼容
  Steam 更新或验证完整性可能覆盖 MOD。游戏构建未变时可重新安装。
  游戏更新后需要与新版本匹配的 MOD 包。
  不支持与其他修改 app.asar 的 MOD 叠加；没有自动合并功能。
  原双人模式文件 main.swf 未改动。

当前验证范围
  已在原电脑的正式游戏验证启动、双角色、独立操作和共享计分。
  安装器另在隔离的游戏文件副本中验证安装、重复安装、卸载、版本不匹配和损坏包处理。
  尚未在另一台实体电脑上验证，也未逐关通关或完整覆盖所有后期机关、道具组合。
  保留游戏原有存档、成就和排行榜逻辑，没有建立独立的 MOD 记录系统。

文件
  Install.cmd / Uninstall.cmd：安装和恢复入口。
  Manage-Mod.ps1：可读的安装器源码。
  manifest.json：支持版本、输入输出哈希与差分操作。
  payload.gz：压缩差分数据；不能单独使用。
